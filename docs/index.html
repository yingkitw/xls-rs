xls-rs

The pure-Rust XLSX toolkit

Fast, memory-efficient, pure-Rust spreadsheet library and CLI for reading, writing, and analyzing XLSX files. No Microsoft Excel, Python, or JVM runtime dependencies.

Quick Overview

# Install or build from source
cargo build --release

# Read and inspect spreadsheets
xls-rs read data.xlsx
xls-rs info data.xlsx
xls-rs sheets data.xlsx

# Run pandas-style transformations
xls-rs head data.xlsx -n 10
xls-rs filter -i data.xlsx -w "Price > 100"
xls-rs groupby -i data.xlsx -g Category -a sum -c Sales
